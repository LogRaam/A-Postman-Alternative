## `tests/request.test.mjs`

What the editor's draft becomes when it is sent: the address, the headers, the body and the warnings.

### The address

- adds https when the address has no scheme
- appends enabled parameter rows after the query the address already has
- skips unticked rows and rows without a name
- refuses an empty address with an example of a good one
- refuses schemes other than http and https

### Headers

- are sent in the order typed
- a header the browser forbids is not sent, and the user is told
- forbidden names include the proxy- and sec- families, in any case

### The body

- a JSON body is checked and gets a JSON content type when none was typed
- a content type the user typed is kept as typed
- invalid JSON stops the send with the parser reason
- GET and HEAD send no body, and the user is told
- raw text is sent as typed with no content type added
